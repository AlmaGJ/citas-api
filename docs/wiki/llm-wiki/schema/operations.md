# Operaciones

## INGEST

Verificar la fuente, registrar su hash en `raw/sources.md`, sintetizar conocimiento durable, enlazar páginas, actualizar `wiki/index.md` y registrar el evento.

## QUERY

Leer `wiki/index.md`, consultar páginas relevantes y verificar la respuesta contra fuentes, código y especificaciones actuales. Separar evidencia de inferencia.

## LEARN

Persistir solo conocimiento durable y clasificarlo como HECHO, DECISIÓN, PREFERENCIA o PREGUNTA ABIERTA.

## LINT

Buscar contradicciones, claims obsoletos, duplicados, páginas huérfanas, enlaces rotos, decisiones no aprobadas y contenido sensible.
