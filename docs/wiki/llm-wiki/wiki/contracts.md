# Contratos

El contrato REST todavía no está definido. El PRD exige que se diseñe y documente durante el proyecto, y que el frontend consuma directamente Spring Boot.

Pendientes que no deben resolverse por inferencia: endpoints y versionado, payloads y errores, autorización por rol/ownership, formato de disponibilidad, retención y expiración de slots, webhooks n8n, CORS y zona horaria.
