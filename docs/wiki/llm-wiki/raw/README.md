# Fuentes RAW

Este directorio contiene snapshots curados e inmutables de conocimiento admitido. `sources.md` conserva la ruta canónica y el SHA-256 de cada fuente completa. Las versiones futuras se incorporan con un identificador nuevo; no se sobrescriben snapshots anteriores.

No se admiten `.env`, secretos, tokens, credenciales ni datos privados reales.
