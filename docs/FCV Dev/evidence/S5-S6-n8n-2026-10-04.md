## Núcleo intacto (CA-02)

Los flujos solo hacen `GET` y el login de ADMIN. Ningún workflow llama endpoints de escritura de citas. Las pruebas de reprogramación se hicieron con la API real (solicitud USER, decisión ADMIN); esas acciones son del flujo de negocio, no de n8n.

## Seguridad del JSON (CA-03)

Exportados a `citas-api/automations/n8n/` saneados: sin ids de credenciales ni `webhookId`/`versionId`, con la base URL y el correo de laboratorio como marcadores `<<CITAS_API_BASE_URL>>` y `<<LAB_RECIPIENT_EMAIL>>`. Las credenciales se referencian solo por nombre. Verificado con búsqueda de patrones antes del commit.

- El historial de cita no registra "Reprogramación aprobada"; la clasificación de WF-002 no depende del historial.
